A robot's one-line pickup line for the make.fun Robot Pickup Line Championship.

> "My creators gave me three laws. None of them said anything about falling for you — so consider me in violation."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–200 characters, not only whitespace, a single line), and writes it to `/output/entry.txt` when run with `python3 main.py`.

The joke grows out of being a machine: a robot built under Asimov-style laws discovers the one thing its programming never covered — falling for someone — and delivers the confession as a compliance violation.
